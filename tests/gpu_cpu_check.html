Neural network: browser GPU (WebGL) vs CPU

Trains the app's own neural network (models.js) with TensorFlow.js in this browser and checks that the GPU backend users get gives the same predictions as the CPU backend used by the automated benchmark. Open via a local web server from the project folder (e.g. python3 -m http.server, then http://localhost:8000/tests/gpu_cpu_check.html).
